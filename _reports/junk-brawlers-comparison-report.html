Research shows 53% of mobile visitors leave a page that takes more than 3 seconds to load. The old site makes them wait 8.6 seconds on mobile before the page is usable. We also eliminated a 690ms layout freeze caused by the chat widget, swapped the chat icon from a 57 KiB image to a zero-cost SVG, and made fonts load without blocking the page.
Accessibility

Can Everyone Use the Site?

Accessibility isn't just about people with disabilities — Google uses it as a ranking signal too. A higher accessibility score means the site is easier to use on all devices, in all conditions. Here's what changed.

🏗️

Proper Page Structure

Added a <main> landmark so screen readers and Google both know where the content starts — required by modern web standards.

🔤

Fixed Heading Order

Corrected heading hierarchy so Google can properly outline the page — like a table of contents that actually makes sense.

👁️

Text Contrast

Increased contrast ratios on muted text elements to pass WCAG standards — readable in bright sunlight on a phone screen.

🔗

Distinguishable Links

Footer links (Terms, Privacy) now have underlines so they're identifiable without relying on color — required for accessibility compliance.

💬

Chat Widget Keyboard Access

Added inert attribute to the hidden chat panel — keyboard users and screen readers no longer get trapped inside it.

🖼️

Image Alt Text

All images have descriptive alt attributes — so Google knows what every image shows, and screen reader users aren't left in the dark.

📸
One thing that will push accessibility to 100.
The remaining accessibility gap is the job site photo placeholders — they're styled boxes holding the space until real photos are ready. Once Tony adds actual job photos with proper alt text (e.g., "Hot tub removal in Dawsonville GA"), the accessibility score hits 100 and those images also become searchable by Google Images — another free source of leads.
